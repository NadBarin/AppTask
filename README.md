### Дипломная работа "Менеджер задач для android"
Приложение реализованно с помощью фреймворка KiviMD.
Задачи можно создавать, удалять и помечать как сделанные. Также можно создавать подзадачи и в 
отдельных вкладках просматривать статистику по выполненным задачам.

Также приложен файл [buildozer.spec](buildozer.spec) для сборки apk пакета.
